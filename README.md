## Раздел 1. Попап (модальное окно)

### Теория

Попап — всплывающее окно, которое обычно перекрывает основной контент. В вёрстке он уже присутствует, но скрыт с помощью CSS-правила `display: none`. Чтобы показать попап, нужно убрать этот `display` (например, добавить класс, который переопределяет стиль).

**Ключевые моменты:**

- Попап имеет две части: затемнение (`.popup-overlay`) и само окно (`.popup`). В данной вёрстке они объединены, но закрытие по клику на оверлей также нужно предусмотреть.
- Открытие: при клике на кнопку `#show-popup` у `.popup-overlay` нужно добавить класс, который делает его видимым (например, `popup-overlay--show`). Однако изначального такого класса в CSS нет — вы можете добавить его сами в `styles.css` или управлять через `style.display`.
- Закрытие: по клику на кнопку с классом `.popup-close` или по клику на сам оверлей (но не на внутреннее окно).

**Пример изменения стиля через JavaScript:**

```javascript
const popup = document.querySelector('.popup-overlay')
// показать
popup.style.display = 'flex' // или 'block', в зависимости от исходного CSS
// скрыть
popup.style.display = 'none'
```

Более чистый способ — добавлять/удалять класс:

```css
.popup-overlay {
    display: none;
}
.popup-overlay.show {
    display: flex;
}
```

```javascript
popup.classList.add('show')
popup.classList.remove('show')
```

**Обработка событий:**

```javascript
const openBtn = document.querySelector('#show-popup')
openBtn.addEventListener('click', () => {
    // показать попап
})
```

Не забудьте предотвратить всплытие событий, чтобы клик по внутреннему окну не закрывал попап.

## Раздел 2. Аккордеон

### Теория

Аккордеон — набор сворачиваемых блоков. При клике на заголовок соответствующее содержимое плавно раскрывается или скрывается.

**Структура в HTML:**

```html
<div class="accordion-item">
    <div class="accordion-header">Наша миссия</div>
    <div class="accordion-content">
        <div class="accordion-content-inner">текст...</div>
    </div>
</div>
```

По умолчанию содержимое скрыто. Сделать его видимым можно разными способами:

- **Простой способ** — `display: none` / `display: block`. Но анимации не будет.
- **С анимацией** — использовать `max-height` и `transition`. Скрытый блок имеет `max-height: 0`, `overflow: hidden`. При раскрытии `max-height` устанавливается в точную высоту контента (`scrollHeight`).

**Пример кода для анимированного аккордеона:**

```javascript
const headers = document.querySelectorAll('.accordion-header')
headers.forEach((header) => {
    header.addEventListener('click', () => {
        const content = header.nextElementSibling
        const isOpen = header.classList.contains('active')
        if (isOpen) {
            content.style.maxHeight = null
        } else {
            content.style.maxHeight = content.scrollHeight + 'px'
        }
        header.classList.toggle('active')
    })
})
```

CSS для этого подхода:

```css
.accordion-content {
    max-height: 0;
    overflow: hidden;
    transition: max-height 0.3s ease-out;
}
```

## Раздел 3. Вкладки (Табы)

### Теория

Вкладки позволяют переключать разные блоки контента. В вёрстке есть:

- Контейнер `.tab-header` с кнопками `.tab-btn`.
- Блоки `.tab-content` с разными `id`.

При клике на кнопку:

1. У всех кнопок удаляется класс `active`.
2. Текущей кнопке добавляется класс `active`.
3. У всех контентных блоков удаляется класс `active` (или скрываются через `display: none`).
4. Контентному блоку, чей `id` соответствует значению `data-tab` кнопки, добавляется класс `active` (или показывается).

В исходном CSS уже есть класс `.tab-content.active` с `display: block`. Изначально активна первая вкладка.

**Получение данных из атрибута:**

```javascript
const tabId = button.getAttribute('data-tab')
const targetContent = document.getElementById(tabId)
```

**Удаление классов у всех элементов:**

```javascript
document
    .querySelectorAll('.tab-btn')
    .forEach((btn) => btn.classList.remove('active'))
```

## Раздел 4. Тултипы (всплывающие подсказки)

### Теория

Тултип — небольшое текстовое пояснение, появляющееся при наведении на элемент. В вёрстке каждый тултип представлен так:

```html
<div class="tooltip">
    <img src="..." alt="..." />
    <span class="tooltip-text">Описание проекта</span>
</div>
```

По умолчанию `.tooltip-text` скрыт (например, `display: none` или `opacity: 0`). При наведении мыши на `.tooltip` нужно показать скрытый текст.

**События:** `mouseenter` / `mouseleave` или `mouseover` / `mouseout`.

```javascript
const tooltips = document.querySelectorAll('.tooltip')
tooltips.forEach((tooltip) => {
    tooltip.addEventListener('mouseenter', () => {
        const text = tooltip.querySelector('.tooltip-text')
        text.style.display = 'block' // или 'inline-block'
    })
    tooltip.addEventListener('mouseleave', () => {
        const text = tooltip.querySelector('.tooltip-text')
        text.style.display = 'none'
    })
})
```

Также можно управлять через добавление/удаление класса.

## Раздел 5. Слайдер (карусель)

### Теория

Слайдер позволяет листать слайды (горизонтально). В вёрстке:

```html
<div class="slider-container">
    <div class="slider">
        <div class="slide">...</div>
        <div class="slide">...</div>
        <div class="slide">...</div>
    </div>
    <div class="slider-arrow slider-arrow-left">&lt;</div>
    <div class="slider-arrow slider-arrow-right">&gt;</div>
    <div class="slider-dots">
        <div class="slider-dot active"></div>
        <div class="slider-dot"></div>
        <div class="slider-dot"></div>
    </div>
</div>
```

Принцип работы:

- Контейнер `.slider` имеет `display: flex`, каждый слайд занимает `min-width: 100%`.
- Сдвиг осуществляется через `transform: translateX(-N%)`, где N — номер текущего слайда (0, 1, 2...).
- Количество слайдов можно получить через `document.querySelectorAll('.slide').length`.
- При клике на правую стрелку увеличиваем `currentSlide` на 1, при клике на левую — уменьшаем, не выходя за границы (0 … slidesCount-1).
- Затем применяем `transform`.
- Также нужно обновлять активную точку (удаляем класс `active` у всех точек и добавляем текущей).

**Пример вычисления смещения:**

```javascript
slider.style.transform = `translateX(-${currentSlide * 100}%)`
```

**Сброс анимации:** в CSS у `.slider` прописан `transition: transform 0.5s ease`, поэтому сдвиг будет плавным.
